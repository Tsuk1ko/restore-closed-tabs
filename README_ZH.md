# 恢复已关闭的标签页

[![](https://developer.chrome.com/static/docs/webstore/branding/image/UV4C4ybeBTsZt43U4xis.png)](https://chromewebstore.google.com/detail/bmancocnclojmcogdgdmgjpbknagdale)

这是一款 Chrome 扩展，可保存已关闭标签页的历史记录，并通过弹出窗口搜索和恢复标签页，项目使用 WXT、Vue、Nuxt UI 和 Dexie 构建

## 环境要求

- Google Chrome
- 用于从源码构建的 Bun

## 安装

```bash
bun install
bun run build
```

在 Chrome 中将 `.output/chrome-mv3` 作为未打包扩展程序加载

## 快速开始

1. 关闭一个具有标题且网址受支持的标签页
2. 打开扩展弹出窗口，查看按关闭时间从新到旧排列的记录
3. 左键点击记录可在前台恢复标签页，中键点击可在后台恢复

默认情况下，恢复后仍保留记录，如需自动移除，可在设置页开启**恢复后删除记录**

## 功能

- 按标题或网址搜索，匹配时不区分大小写，并支持分页浏览
- 查看标题、网址、网站图标和相对关闭时间，将鼠标悬停在时间上可查看完整时间
- 右键点击记录可复制标题、网址或超链接，也可删除该记录
- 从弹出窗口打开设置页，调整语言、记录容量、每页条数、窗口宽度和记录规则
- 在设置页导出、导入或清空已关闭标签页记录

## 设置

| 设置项                          | 默认值     | 说明                                           |
| ------------------------------- | ---------- | ---------------------------------------------- |
| 语言                            | 跟随浏览器 | 也可选择简体中文、繁体中文或英语               |
| 最大记录条数                    | 1,000      | 范围为 100–10,000，应用上限时删除最旧记录      |
| 每页条数                        | 10         | 范围为 5–100                                   |
| 弹出窗口宽度                    | 400 px     | 范围为 280–800 px                              |
| 恢复后删除记录                  | 关闭       | 成功重新打开标签页后删除对应记录               |
| 记录时清除相同网址的旧记录      | 关闭       | 关闭标签页时按完全相同的网址去重               |
| 无痕模式下启用记录              | 关闭       | 还需在 Chrome 扩展设置中启用“在无痕模式下启用” |
| 记录 `chrome://` 页面           | 关闭       | 始终排除 `chrome://newtab/`                    |
| 记录 `chrome-extension://` 页面 | 关闭       | 恢复时部分扩展页面可能无法访问                 |

默认记录具有标题的 `http:` 和 `https:` 标签页，其他网址协议（包括 `file:`）均不记录

修改最大记录条数后不会立即裁剪已有历史，新增关闭记录或导入记录时才会应用上限

## 数据与限制

已关闭记录、设置和当前标签页快照保存在本地 IndexedDB 中

导出的 JSON 只包含已关闭记录，不包含设置或当前标签页快照

导入支持本扩展的第 1 版 JSON 格式，新记录会加入历史，相同 ID 的记录会被覆盖，随后应用记录数量上限

清空历史仅删除已关闭记录

后台服务工作线程会保存当前标签页的快照，并在重新启动时恢复未完成的处理

Chrome 没有可靠的浏览器退出事件，因此崩溃、强制终止或断电后仍可能丢失最后关闭的标签页记录，受限制或已失效的页面也可能无法重新打开
